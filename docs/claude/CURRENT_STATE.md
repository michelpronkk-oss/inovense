# Auterim current state

Auterim is an AI workforce platform for businesses.

Approved loop: Connect → Understand → Diagnose → Recommend → Deploy → Measure → Improve.

Auterim finds where time, money, and opportunities are being lost, explains why, recommends the appropriate AI workforce, deploys it with controls, and measures business impact.

Hosts: https://auterim.com (marketing), https://app.auterim.com (customer software), https://admin.auterim.com (internal admin). `portal.auterim.com` is retired and redirects to the app.

Legacy integration and persistence identifiers remain intentionally unchanged for compatibility.
